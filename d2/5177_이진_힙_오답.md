[오답 원인 4가지]
1. IndexError (인덱스 에러)
- __init__에서 self.__A = []로 빈 리스트를 생성한 뒤, insert에서 self.__A[i] = x를 호출하면
존재하지 않는 인덱스에 접근하려 하므로 IndexError가 발생합니다.
리스트에 요소를 추가할 때는 self.__A.append(x)를 사용해야 합니다.

2. NameError (변수명 에러)
- insert 메서드 안의 while 조건문에서 A[i] < A[parent]라고 작성했는데,
클래스 내부의 변수명은 self.__A이므로 self.__A[i] < self.__A[parent]로 수정해야 합니다.

3. 무한 루프 발생 (업힙 과정의 인덱스 갱신 누락)
- while문 안에서 노드가 위로 올라갈 때 i와 parent의 값
  (i = parent, parent = (i - 1) // 2)을 다시 갱신해 주지 않으면,
조건이 맞을 때 루프를 빠져나가지 못하고 무한 루프에 빠지게 됩니다.

4. 논리 오류 (ssum 메서드)
- 문제에서 요구하는 것은 조상 노드에 저장된 정수 값들의 합인데, total += parent라고 작성하여
노드의 인덱스 번호를 더하고 있었습니다. total += self.__A[parent]로 수정해야 합니다.
