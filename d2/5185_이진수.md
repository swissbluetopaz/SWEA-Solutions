16진수 1자리는 2진수 4자리로 표시된다.

N자리 16진수가 주어지면 각 자리 수를 4자리 2진수로 표시하는 프로그램을 만드시오.

단, 2진수의 앞자리 0도 반드시 출력한다.

예를 들어 47FE라는 16진수를 2진수로 표시하면 다음과 같다.

0100011111111110


[입력]

첫 줄에 테스트케이스의 수 T가 주어진다. 1<=T<=50

다음 줄부터 테스트 케이스의 별로 자리 수 N과 N자리 16진수가 주어진다. 1<=N<=100

16진수 A부터 F는 대문자로 표시된다.
 
[출력]

각 줄마다 "#T" (T는 테스트 케이스 번호)를 출력한 뒤, 답을 출력한다.

[내 풀이]
1. 진법 변환과 int() 함수
- 기본 개념 : 파이썬은 문자열을 특정 진법의 숫자로 쉽게 바꿀 수 있는 기능을 제공합니다.
- 사용 예시 : int(char, 16)
  - 16은 "이 문자열이 16진수야"라고 알려주는 진법 지정 인수입니다.
  - 이 기능을 모르면 A는 10, B는 11... 이렇게 일일이 if-else 조건문을 써서 변환해야 하지만,
    int() 함수 하나로 해결할 수 있어 기초 실무와 코딩 테스트에서 필수적입니다.

2. f-string(문자열 포맷팅)과 2진수 변환
- 기본 개념 : 문자열 안에 변수나 연산 결과를 쉽게 넣는 방법입니다. 파이썬 3.6 이상부터 지원하는
f-string(f"...")은 현대 파이썬의 표준이자 가장 권장되는 방식입니다.
- 사용 예시 : f"{val:04b}"
  - : 뒤에 오는 포맷 지정자는 숫자를 다룰 때 정말 유용합니다.
  - b : 2진수(binary)로 변환
  - 04 : 총 4자리를 확보하고, 빈 자리는 0으로 채움 (이 문제의 핵심 조건인 "앞자리 0 출력"을 해결하는
  핵심 문법입니다)

=> 16진수 글자 하나를 int()를 통해 10진수 정수로 변환한다.
이후 10진수를 format() 함수를 사용하여 4자리 이진수 문자열로 변환한다.
